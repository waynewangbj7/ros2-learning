# ROS 2 双节点实时红色识别：最终记录

本次先跑通古月居第 8 节的图像发布—订阅链路，再把相机发布端从课程的 `topic_webcam_pub` 换成 `usb_cam`。两种方案使用同一个 `topic_webcam_sub`；替换时没有改识别代码或 HSV 阈值。用户确认 `usb_cam` 方案能弹出实时画面并圈出红色物块。

```text
topic_webcam_pub（OpenCV）或 usb_cam（二选一）
    → /image_raw [sensor_msgs/msg/Image]
    → topic_webcam_sub [CvBridge 转 bgr8 → HSV 红色筛选 → 显示绿色轮廓]
```

这是节点级模块化：可以替换采集端，识别端只依赖话题接口。换其他相机时仍需匹配设备、采集格式、话题名、消息类型、可转换的图像编码及兼容的 QoS；`usb_cam` 不是所有相机的通用驱动。

## 验证结果

| 阶段 | 当次证据 |
| --- | --- |
| WSL 摄像头取帧 | 重接后 `/dev/video0` 可用；单独使用 V4L2、MJPG、320×240 连续读到 5 帧，每帧形状 `(240, 320, 3)`。 |
| 课程 OpenCV 双节点 | `ros2 topic echo` 收到 `320×240`、`bgr8`、`step: 960`、像素数据 `230400` 字节；订阅端弹窗圈出包装红色区域，见[原始截图](../../../raw/experiments/2026.11.23_ROS2双节点视觉_ROS2-B-261123-001/opencv-dual-node.png)。 |
| 替换为 `usb_cam` | 启动日志记录 `/dev/video0`、320×240、`mmap`、`mjpeg2rgb`，请求 30 FPS，定时器间隔 33 ms。发布和订阅在两个 Ubuntu 终端同时运行后，用户确认实时画面和红色物块识别正常。 |

截图是课程 OpenCV 双节点阶段的证据，不是 `usb_cam` 换装后的截图。`usb_cam` 换装以启动日志和用户确认记录；未记录其单帧 `echo` 输出，未测实际帧率、延迟或识别率，也未验证其他型号相机。

## 下次怎么跑（usb_cam 方案）

1. **Ubuntu 查设备。** 运行 `ls -l /dev/video*`。如果没有设备，保持 Ubuntu 开着，到 Windows PowerShell 执行 `usbipd list`，找内置摄像头 `04f2:b758`。若状态为 `Shared`，执行 `usbipd attach --wsl --busid 2-6`（以当前列表里的 BUSID 为准）。确认 `Attached` 后回 Ubuntu；必要时执行 `sudo modprobe uvcvideo` 再查。若 `/dev/video0` 仍为 `crw------- root root`，确认是该摄像头后，执行 `sudo chown "$USER" /dev/video0` 临时授权。只授权本次使用的设备。
2. **Ubuntu 终端 A 跑发布端。** 先停掉旧 `topic_webcam_pub` 或单节点 `node_object_webcam`，避免抢占摄像头。`sudo apt install ros-jazzy-usb-cam` 只需安装一次，当前机器已安装。用普通用户运行下列命令，保持终端 A 运行。

```bash
source /opt/ros/jazzy/setup.bash
ros2 run usb_cam usb_cam_node_exe --ros-args \
  -p video_device:=/dev/video0 \
  -p pixel_format:=mjpeg2rgb \
  -p image_width:=320 \
  -p image_height:=240
```

3. **Ubuntu 终端 B 跑订阅端。** 不要先按 `Ctrl+C` 停掉终端 A。若订阅端已经在等帧，不用重复启动。

```bash
source /opt/ros/jazzy/setup.bash
source /home/wzy/guyue_ros2_ws/install/local_setup.bash
ros2 run learning_topic topic_webcam_sub
```

4. **验证。** `object` 窗口画面跟着动作变化、红色物块被圈出，即确认识别。若不弹窗，在另一个已加载 Jazzy 的 Ubuntu 终端，用 `ros2 topic echo /image_raw sensor_msgs/msg/Image --once --timeout 15 --no-arr` 检查是否有帧。15 秒只限制检查命令，两个节点不设自动停止时间。用完后分别停止两端；需要把摄像头还给 Windows 时，在 PowerShell 执行 `usbipd detach --busid 2-6`（以当前 BUSID 为准）。
